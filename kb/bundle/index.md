# Knowledge base

Shared memory for your bots and agents. Read this page first, then the index of the folder you need, then only the pages you need.

## Folders

- [Topics](topics/index.md) - How you work: practices, plans and ideas that span projects.
- [References](references/index.md) - Facts looked up from outside sources, each with its date and source.
- [Decisions](decisions/index.md) - Choices you made and why, numbered in order.
- [Questions](questions/index.md) - Answers worth keeping, filed back so they aren't lost in a chat.
